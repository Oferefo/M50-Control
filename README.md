# M50 Control

אפליקציית ווב מקומית לשליטה ב-Canon EOS M50 דרך USB (libgphoto2).

## הפעלה

```bash
./run.sh
```

נפתח בדפדפן: http://localhost:5050

או: לחיצה כפולה על **M50 Control** בשולחן העבודה. חלון הטרמינל שנפתח צריך להישאר פתוח —
סגירתו עוצרת את האפליקציה. לחיצה כפולה כשהאפליקציה כבר רצה רק פותחת את הדפדפן.

## מה יש

- התחלה / עצירה של צילום וידאו, עם טיימר
- **התחלה מחדש אוטומטית**: אם המצלמה עוצרת לבד (מגבלת 29:59, כפתור, חום) — מתחיל שוב מיד
- פיצול קבצים כל N דקות (אופציונלי)
- **תזמון**: התחלה בשעה, ועצירה בשעה או אחרי משך (למשל 90 דק').
  העצירה המתוזמנת סופית — גוברת על "התחל מחדש". יחד עם "התחל מחדש" אפשר לצלם מעבר
  למגבלת 29:59 של המצלמה (נוצרים כמה קבצים ברצף).
- המחשב לא נכנס לשינה כל עוד האפליקציה רצה (caffeinate). לא לסגור את המכסה.
- צילום סטילס + הורדה אוטומטית לתיקיית `captures/`
- תצוגה חיה (live view)
- **איכות וידאו**: האפליקציה מציגה את האיכות הנוכחית. שינוי — רק מתפריט המצלמה.
  (ניסיון לשנות מהמחשב עם `ptp_raw.py` התקבל, אבל אחריו המצלמה נתקעה ומסכה החשיך; כבוי.)
- הגדרות: ISO, תריס, צמצם, פיצוי חשיפה, איזון לבן, פוקוס ועוד
- רשימת קבצים חדשים בכרטיס והורדה למחשב, יומן אירועים

## חשוב לדעת

- **עמידות לקריסה**: libgphoto2 קורסת לפעמים (segfault) על אירוע מוזר מהמצלמה.
  `serve.sh` מפעיל את האפליקציה מחדש תוך 2 שניות, ו-`state.json` שומר צילום/תזמון/התחל-מחדש —
  כך שצילום ארוך ממשיך. (נבדק: קריסה באמצע צילום — המצלמה המשיכה לצלם.)
- **Google Chrome תופס את המצלמה** ב-USB, וכשהוא פתוח תחילת צילום תוקעת את המצלמה. האפליקציה
  מזהה את זה, מציגה אזהרה אדומה וחוסמת התחלת צילום. האייקון פותח את האפליקציה ב-Safari. בדיקה ידנית:
  `ioreg -l -w0 -r -n "Canon Digital Camera" | grep IOUserClientCreator`
- **רק תוכנה אחת יכולה לשלוט במצלמה.** צריך לסגור את EOS Webcam Utility
  (גם את השירות שלו `com.canon.usa.EWCService`, שחוזר אחרי הפעלה מחדש של המחשב).
  האפליקציה מעיפה לבד את `ptpcamerad` של macOS.
- **וידאו / סטילס** נקבע בחוגה הפיזית של המצלמה. האפליקציה מזהה את המצב
  ומפעילה את הכפתורים המתאימים.
- כדאי לבטל במצלמה: חיסכון חשמל ← כיבוי אוטומטי ← מבוטל.
- **תפריט המצלמה**: כשהתצוגה החיה באפליקציה דלוקה, המצלמה יוצאת מהתפריט אחרי כמה שניות,
  והמסך שלה חשוך. כדי לשנות הגדרות במצלמה — כבה את התצוגה החיה.
- לא לשנות מהמחשב את "Camera Output" (`output`): ב-M50 כל שינוי שלו גורם לפקודת
  ההקלטה הבאה לתקוע את המצלמה עד ניתוק חשמל.
- ה-M50 מחזיר "Device Busy" לפקודת הקלטה אם ה-live view לא פעיל — לכן
  האפליקציה מדליקה אותו ומחכה רגע לפני כל התחלת צילום.
